# Agent Bot portraits

Original AI-generated transparent PNG mascots created for the Sesama Agent Bot demo on 4 November 2026.

- `atlas-v1.png`: warm orange rounded diamond; coordinator.
- `forge-v1.png`: mint/emerald rounded cube; builder.
- `scout-v1.png`: azure rounded kite; researcher.

Shared direction: tactile frosted clay/resin, two ivory eyes, soft upper-left studio lighting, no lettering or background. Files retain the generated alpha channel. The demo consumes them through the central Avatar builder, including the main agent tab and settings identity preview. Fork tabs retain their navigation icon.
