# Security

This is a pre-release UI project. No hosted authentication, AI backend, or storage service is provided.

Please do not put credentials, private files, or exploit details in public issues. Use GitHub private vulnerability reporting if it is enabled for this repository; otherwise contact the maintainer privately through their published contact channel before disclosing details. No response-time guarantee is currently published.

HTML content slots and render callbacks accept trusted developer content. Do not insert untrusted model output or user HTML without an appropriate sanitization policy. The package migration includes an explicit trust-boundary review.
